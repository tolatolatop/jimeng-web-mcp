## 一、功能概述

为JiMeng Web MCP Server添加2K/4K分辨率选择功能，用户可以选择生成2K或4K高分辨率图片。

## 二、DevTools验证的4K尺寸

通过Chrome DevTools实际抓取JiMeng网站的4K图片生成请求，验证了所有宽高比的真实尺寸：

| 宽高比 | 2K尺寸 | 4K尺寸（DevTools验证） |
|--------|--------|----------------------|
| auto/智能 | 2048×2048 | **4096×4096** |
| 1:1 | 2048×2048 | **4096×4096** |
| 16:9 | 2560×1440 | **5404×3040** |
| 9:16 | 1440×2560 | **3040×5404** |
| 4:3 | 2304×1728 | **4693×3520** |
| 3:4 | 1728×2304 | **3520×4693** |
| 3:2 | 2496×1664 | **4992×3328** |
| 2:3 | 1664×2496 | **3328×4992** |
| 21:9 | 3024×1296 | **6197×2656** |

### 关键发现

1. **4K非标准倍数**: JiMeng的4K尺寸不是简单的2K×2倍，而是基于自定义的高分辨率标准
2. **1:1比例基准**: 4K的1:1比例为4096×4096（标准4K像素数）
3. **其他比例**: 基于4096基准按宽高比计算，与标准4K UHD(3840×2160)不同
